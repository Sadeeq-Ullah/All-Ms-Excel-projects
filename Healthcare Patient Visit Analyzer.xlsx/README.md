# 🏥 Healthcare Patient Visit Analyzer

## 🔍 Overview
An Excel analytics workbook built to surface patient visit patterns, rejected claims, no-show risk, and satisfaction trends.

## 📁 Included files
- `Healthcare Patient Visit Analyzer.xlsx` — the main analytics workbook.
- `Project Documenation.pdf` — supporting project documentation.
- `Cleaned data.PNG` — cleaned dataset preview.
- `Dummy data.PNG` — sample test record snapshot.
- `Filtered data.PNG` and `Filtered data (2).PNG` — filtered analytics views.

## ✨ Highlights
- Identifies rejected claims and no-show appointments.
- Summarizes department-level patient satisfaction.
- Supports operational healthcare insights.
- Delivers analytics-ready data and charts.

## 🚀 Quick start
1. Open `Healthcare Patient Visit Analyzer.xlsx` in Excel.
2. Review the key analytics worksheets and visuals.
3. Consult the documentation for methodology and context.

## 💡 Why this matters
This workbook helps healthcare teams understand visit flow, reduce no-shows, and improve care delivery decisions.
