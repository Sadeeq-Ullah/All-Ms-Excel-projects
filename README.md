## 🚀 Project lineup

### 1. Customer Data Cleaning
- **Location:** `Customer Data Cleaning`
- **Main workbook:** `Data cleaning.xlsx`
- **Focus:** Standardize customer records, normalize emails, format phone numbers, and clean location data.
- **Why it stands out:** Turns messy raw data into a clean customer dataset ready for reporting.

### 2. Invoice Bill
- **Location:** `invoice bill`
- **Main workbook:** `invoice bill.xlsx`
- **Focus:** Create a professional billing document with clear line items and totals.
- **Why it stands out:** Produces a business-ready invoice layout and a polished PDF sample.

### 3. RetailOps Recovery Audit
- **Location:** `RetailOps Recovery Audit`
- **Main workbook:** `RetailOps Recovery Audit.xlsx`
- **Focus:** Support retail audit and recovery analysis with structured review.
- **Why it stands out:** Centralizes retail recovery insights for operational improvement.

### 4. UrbanCart Sales & Inventory Dashboard
- **Location:** `UrbanCart-Sales & Inventory Dashboard`
- **Main workbook:** `SALES & INVENTORY DASHBOARD.xlsm`
- **Focus:** Present interactive sales, inventory, and store performance analytics.
- **Why it stands out:** Delivers a visually compelling dashboard experience.

### 5. Healthcare Patient Visit Analyzer
- **Location:** `Healthcare Patient Visit Analyzer.xlsx`
- **Main workbook:** `Healthcare Patient Visit Analyzer.xlsx`
- **Focus:** Analyze patient visits, rejected claims, no-shows, and satisfaction metrics.
- **Why it stands out:** Reveals operational trends and clinical workflow insights.
