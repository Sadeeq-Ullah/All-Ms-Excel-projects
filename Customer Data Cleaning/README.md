# 🧹 Customer Data Cleaning

## 🔍 Overview
A high-impact Excel project that upgrades raw customer data into clean, reliable records ready for reporting and analytics.

## 📁 Included files
- `Data cleaning.xlsx` — the main workbook with raw input and cleaned output.
- `Dirty data.PNG` — sample of inconsistent source data.
- `cleaned data.PNG` — sample of the final polished dataset.

## ✨ Highlights
- Standardizes customer IDs, names, email addresses, and phone numbers.
- Harmonizes city, state, and country values.
- Delivers consistent customer status and spending fields for reporting.

## 🚀 Quick start
1. Open `Data cleaning.xlsx`.
2. Compare the raw dataset to the cleaned customer table.
3. Use the workbook as a reference for customer data quality improvement.

## 💡 Why this matters
Clean customer data enables more accurate analysis, better customer segmentation, and dependable business intelligence. This workbook demonstrates polished data preparation in Excel.
