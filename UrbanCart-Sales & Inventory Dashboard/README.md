# 📊 UrbanCart Sales & Inventory Dashboard

## 🔍 Overview
A high-impact Excel dashboard built to showcase sales performance, inventory trends, and store metrics.

## 📁 Included files
- `SALES & INVENTORY DASHBOARD.xlsm` — the macro-enabled dashboard workbook.
- `raw data.PNG` — sample source dataset snapshot.
- `cleaned data.PNG` — cleaned data preview.
- `dashboard.PNG` — dashboard visual snapshot.

## ✨ Highlights
- Interactive regional revenue and product category analysis.
- Monthly sales trend visualization.
- Store performance and inventory insights.

## 🚀 Quick start
1. Open `SALES & INVENTORY DASHBOARD.xlsm`.
2. Enable macros when prompted.
3. Explore dashboard visuals and filters.

## 💡 Why this matters
This workbook turns retail data into clear, executive-ready insights for better sales and inventory decisions. It supports better decisions with clear, actionable visuals.
